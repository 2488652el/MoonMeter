# 本地来源与事件隐私边界

本文件说明 MoonMeter 的 Windows/WSL 来源、项目分析、时间线和本地 OTLP 接收器在 v1.3–v1.6 的数据边界。默认行为优先保证“本机可见、用户显式开启、主进程持有路径”。

## 来源发现

- Windows 首次发现只调用 `wsl.exe --list --quiet` 和尽力而为的 `wsl.exe --list --verbose`。不会在初次发现时使用 `--exec`，不会启动发行版，也不会读取 `$HOME` 或 CLI 目录。
- 只有用户点击“预览目录”或“启用来源”后，Main 才会解析 WSL `$HOME`、构造候选目录并检查目录是否存在。读取日志仍需用户点击同步，或显式打开既有的自动解析开关。
- WSL、Windows 和 macOS 的 CLI 解析器通过注册表共享上下文；路径、发行版和文件读取都由 Main 生成，Renderer 不接受任意路径作为同步输入。
- 来源停用只停止后续读取，不删除已经入库的用量记录。诊断信息只输出平台、发行版数量、来源 ID、状态和错误码，不输出路径、凭据或日志正文。

## 项目与 Git

- `/projects` 的成本、Token、请求、会话和活跃天数由 Main/SQLite 聚合，Renderer 不接收完整的原始日志列表。
- Git 只读调用使用参数数组和超时；只保存 commit ID、作者、时间、标题和 numstat 汇总，不保存文件名、补丁或仓库内容。Git 失败不会阻断用量读取。
- 任务与会话、commit、PR 的关系必须由用户手动建立或确认。PR 只接受不含用户名/密码的 HTTPS URL，不自动访问远端仓库。
- 项目 API 返回稳定项目标识和展示名，不向项目页传递归一化根路径；来源页只有在用户主动检查来源时展示 Main 生成的访问路径。

## 时间线与保留

- 时间线只允许模型、Token、成本、时长、状态、错误码、来源/工作区/任务 ID、commit/PR 元数据等白名单字段。
- Prompt、命令及参数、代码、工具输入/输出、原始请求体和未知字段不会进入时间线事件表，也不会从 OTLP 接收器写入数据库。
- 详细 agent 事件保留 90 天；超过 90 天的事件按天、来源、工作区、任务和类型聚合后删除明细。用量、交付和预算等已有业务数据不因该清理动作删除。
- 事件使用去重键避免重放重复入库；时间线查询由 Main 分页，Renderer 只获得当前页的脱敏事件。

## 本地 OTLP / HTTP JSON

- 接收器默认关闭，只监听 `127.0.0.1`，仅接受 `POST /v1/logs` 的 `application/json`。
- Bearer Token 由 Electron `safeStorage` 加密保存；Token 轮换后仅在当前设置页显示新值。示例脚本使用占位符，不自动修改 Claude、Agent 或其他工具配置。
- 单请求最多 256 KiB、100 条事件，最多 600 请求/分钟；超限、无效 Token、重复事件和解析失败都返回安全错误码。
- 只接受白名单标量字段，并限制字符串、Token、成本和时长范围。接收器不上传数据，不监听非回环地址。

## 同步与删除

- 初始同步协议仍只包含既有的可同步设置、价格和余额快照；本地来源、工作区、任务、时间线和 OTLP 数据默认不进入云端同步。
- 关闭来源、关闭 OTLP 或隐藏 mini panel 不会误删历史用量；时间线“清理旧详情”只执行 90 天 agent 明细到日聚合的保留策略。
